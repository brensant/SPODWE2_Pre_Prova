# Desenvolvimento Web 2 - Atividade pré prova - Site de Notícias/Blog

Desenvolvimento de um site de notícias/blog com HTML, CSS e JavaScript. Praticando conceitos como HTML semântico, variáveis CSS, display flex e grid, media queries, manipulação do DOM, eventListeners, localstorage, JSON e Date() object.

## Requisitos Obrigatórios

**HTML**

- [x] Uso de tags semânticas: header, nav, main, section, article, aside, footer.
- [x] No mínimo 8 notícias, cada uma com título, categoria, autor/data e imagem com alt.
- [x] Código validado, indentado e sem erros de estrutura.

**CSS**

- [x] Paleta própria e tipografia (no mínimo 2 fontes) definidas com variáveis CSS.
- [x] Layout responsivo com Flexbox e/ou Grid e ao menos 1 media query (breakpoint).
- [x] Estados de foco/hover visíveis nos elementos interativos.

**JavaScript**

- [x] Implementar, no mínimo, 2 recursos interativos (ex.: filtro por categoria, busca, tema claro/escuro, formulário com validação, “carregar mais”, relógio).
- [x] Manipulação do DOM com JavaScript puro, sem frameworks ou bibliotecas externas.

**Entrega**

- [x] Arquivos do projeto: index.html, style.css e script.js (ou embutidos no HTML).
- [x] Um README curto com a descrição do design: paleta (hex), fontes usadas e fontes das imagens.
- [x] Formato: link publicado (GitHub).
